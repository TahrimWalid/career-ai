Limitations & Known Issues ⚠️

  • Language data interpretation - 82.5% have Finnish-language postings, but this doesn't definitively mean Finnish is required; many jobs posted in both languages. Initial deduplication bias (95% removal of Finnish posts) showed how easily language data can be misinterpreted.
  • Location data inconsistency - Consolidated 130 variants to 41 cities, but inconsistencies remain ("Helsinki, Finland", "Kouvola, Kouvola", Sofia still present). This is an ongoing limitation, not a solved problem. Suitable for broad clustering, not precise analysis.
  • Single source bias - Duunitori.fi only, other boards not included
  • Temporal snapshot - May 2026 data, trends evolve rapidly
  • LLM extraction variance - Conservative defaults (23% jobs no skills listed)
  • Geographic concentration - 71% in 2 cities, regional variations hidden
  • Company data gaps - 6.5% unknown companies (not specified in posting)
  • Missing context - No salary, benefits, remote work details, company size

Methodological Insights

Deduplication & Bias Detection: Initial naive deduplication removed 95% of Finnish-language postings, making us 72.6% → 5% overnight. Rather than hide this, we documented it: algorithms encode choices that need auditing. Discovering systematic bias in our own approach before publication is actually a strength, not a failure. It's how professional data work identifies problems before they become public errors.
Location Normalization Challenge: While we consolidated locations from 130 to 41 variants, some inconsistencies remain. Rather than pretend they're solved, we acknowledge this as an ongoing limitation. This is real-world data work: some problems are better acknowledged than chased indefinitely.

🔧 Methodology

Phase 1: Index Scraping - Crawled 50 listing pages, extracted 2,002 job URLs

Phase 2: Detail Hydration - Fetched full job pages, extracted metadata (1,966 jobs = 98.2% success)

Phase 3: Deduplication - Identified 1,016 duplicate postings, discovered that naive deduplication systematically removed 95% of French-language posts, revised approach to preserve data integrity

Phase 4: LLM Extraction - Used Ollama qwen2.5:3b to extract skills, roles, seniority (882/986 = 89.5%)

Phase 5: Analytics - Aggregated skills, computed distributions, generated insights
